# Pattern CAD for Windows

가방용 2D 패턴 CAD의 Windows 설치 파일과 업데이트 배포 저장소입니다.

[설치 파일 / 릴리스](https://github.com/GilwooKim/pattern-cad-releases/releases)

Windows 10/11 x64. 현재 Alpha 버전입니다.
0.5.0 이하 사용자는 업데이트 기능을 포함한 설치 파일을 한 번 직접 설치하세요.
이후에는 도움말 > 업데이트 확인 / 설정에서 업데이트할 수 있습니다.
새 버전은 자동 확인·다운로드하며, 작업 저장 후 재시작 설치합니다.

각 릴리스에는 설치 파일, SHA-256 확인 파일, RSA 서명이 포함된 업데이트 정보가 있습니다.
앱은 배포자 서명과 파일 크기·SHA-256을 검증한 뒤 설치합니다.
업데이트 서명과 Windows Authenticode 인증서 서명은 별개입니다.

이 저장소에는 개발 소스, 원본 기획서, 사용자 패턴 파일을 게시하지 않습니다.
GitHub 로그인이 없어도 공개 설치 파일을 다운로드할 수 있습니다.
